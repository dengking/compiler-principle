# Loop optimization



## wikipedia [Loop optimization](https://en.wikipedia.org/wiki/Loop_optimization)

In [compiler theory](https://en.wikipedia.org/wiki/Compiler_theory "Compiler theory"), **loop optimization** is the process of increasing execution speed and reducing the overheads associated with [loops](https://en.wikipedia.org/wiki/Control_flow#Loops "Control flow"). It plays an important role in improving [cache](https://en.wikipedia.org/wiki/Cache_\(computing\) "Cache (computing)") performance and making effective use of [parallel processing](https://en.wikipedia.org/wiki/Parallel_computing "Parallel computing") capabilities. Most execution time of a [scientific program](https://en.wikipedia.org/wiki/Scientific_computing "Scientific computing") is spent on loops; as such, many [compiler optimization](https://en.wikipedia.org/wiki/Compiler_optimization "Compiler optimization") techniques have been developed to make them faster.
