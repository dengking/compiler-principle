# SSA 中的极小性(Minimality)

## 0. 引言

静态单赋值(SSA)构造分为两个阶段:**φ 函数插入**与**变量重命名**。重命名基本是机械替换,全部设计自由度几乎都集中在插入阶段。于是"插多少个 φ"成了 SSA 形式的一个核心质量问题——这就是**极小性(Minimality)**。

一句话概括:

> **在保证单一定义到达(SRDP)成立的前提下,插入的 φ 函数数量尽可能少。**

它既不是正确性条件,也不是任何优化所必需的,而是一个**规范形式(canonical form)**式的质量指标。本文从定位、数学刻画、证明、与相邻概念的区别、工程实践五个层面展开。

---

## 1. 定位:极小性约束的是哪个阶段

| 阶段 | 内容 | 是否被极小性约束 |
|---|---|---|
| ① φ 函数插入 | 在控制流汇合处插入 φ,保证单一定义到达 | **是** |
| ② 变量重命名 | 给每个定义分配唯一名字,完成 SSA 转换 | 否 |

关键点:**极小性描述的是"已经插入 φ、但尚未重命名"的代码的性质**。它的前提是代码已满足 SRDP,极小性在前提之上进一步要求 φ 数量达到最小。

为什么自由度全在阶段 ①?

- 若 φ **放少了**:重命名时某些 use 找不到唯一的到达定义,循环头 φ、lost-copy 等问题随之而来。
- 若 φ **放多了**:重命名是逐点机械替换,救不回来,只会留下一堆无用定义。

所以"放多少"只能在这里把关。

### 形式化前提

定义 $D$ 到达点 $p$ 的含义:

$$
\text{reaches}:\quad D \text{ 到达 } p \iff \exists\, D \to p \text{ 的路径,途中不经另一个 } v \text{ 的定义}
$$

$$
\text{SRDP}:\quad \text{任何程序点都不能被同一变量的两个定义到达}
$$

SRDP 就是经典教材中"待重命名代码满足单一定义性质"的形式化说法。由此:

- **正确性要求 = SRDP**
- **极小性 = 在所有满足 SRDP 的放置方案中,φ 数量最少**

---

## 2. 歧义只可能在汇合点产生

理解 join set 的关键直觉链只有三步:

1. **单前驱块永远不需要 φ**。它唯一的值来源就是那条入边,不存在"选哪个"的问题。
2. **多前驱也不够**。如果所有来路上携带的是**同一个定义**(例如两路都指向 $x_1$),依然没有歧义,此时 φ 是多余的。
3. 真正需要 φ 的位置,是"**两个不同定义各自沿一条路径走来,首次相遇的那个块**"——也就是 join node。

因此 join node 的定义里有一个容易忽略却极其关键的条件:$n_1, n_2$ 必须**互异**。只有两个不同的定义点,才谈得上"两个定义同时到达"。这条立刻给出一个漂亮的推论:

$$
|D_v| = 1 \implies \mathscr{J}(D_v) = \varnothing \implies \text{一个 φ 都不需要}
$$

变量只被赋值一次时,它本来就已经是 SSA 的,任何 φ 都是浪费。

---

## 3. 数学刻画:汇合节点与汇合集

### 3.1 汇合节点(Join Node)

设 $n_1, n_2$ 是 CFG 中两个**互异**的基本块。若存在两条从 $n_1$、$n_2$ 分别出发的非空路径(至少含一条 CFG 边),使得 $n_3$ 是这两条路径上**唯一**的公共基本块(即两路恰在 $n_3$ 汇合,之前没有任何其它公共节点),则称 $n_3$ 是 $n_1$ 与 $n_2$ 的汇合节点。注意 $n_3$ 可以与 $n_1$ 或 $n_2$ 重合(自环、循环头等情形)。

### 3.2 汇合集 $\mathscr{J}(S)$

给定基本块集合 $S$,若 $n_3$ 是 $S$ 中**至少两个**块的汇合节点,则 $n_3$ 是 $S$ 的汇合节点。$S$ 的全体汇合节点记为 $\mathscr{J}(S)$。

### 3.3 主定理:φ 的最小插入位置集合

设变量 $v$ 的原始定义所在基本块集合为 $D_v$,则:

$$
\boxed{\text{φ 恰好、且仅需插入在 } \mathscr{J}(D_v) \text{ 中的每个基本块}}
$$

原文进一步指出:插入的 φ 本身也是定义点,直觉上似乎应对 $D_v \cup \mathscr{J}(D_v)$ 再求一次汇合集、再插一轮。但可以证明

$$
\mathscr{J}\bigl(S \cup \mathscr{J}(S)\bigr) = \mathscr{J}(S)
$$

也就是说,**闭包一次到位,不需要递归迭代**。对原始定义点求一次汇合集,就得到了 φ 的最小插入位置集合。

### 3.4 直观理解

> 汇合集恰好对应 φ 的放置位置。若 $n_1, n_2$ 都含变量 $v$ 的定义,就应在 $\mathscr{J}(\{n_1,n_2\})$ 的每个块为 $v$ 实例化 φ。

---

## 4. 为什么 $\mathscr{J}(D_v)$ "恰好"最少

把命题拆成下界与上界两个方向,才看得出它有多强。

### 必要性(下界)

取任意 join 点 $n_3 \in \mathscr{J}(\{n_1,n_2\})$,并取"最靠下"的那一对路径——即除端点外路径上不再含 $v$ 的其它定义。此时 $n_1$ 与 $n_2$ 的定义**都**到达 $n_3$。

- 若 $n_3$ 处没有 φ,SRDP 当场被破坏;
- 所以任何满足 SRDP 的放置**必须**包含 $\mathscr{J}(D_v)$;
- 而在别的块上放 φ 又都是浪费(见第 2 节)。

### 充分性(上界)

在每个 join 点放 φ 后,φ 自身成为一个"唯一的定义"。按拓扑序归纳:每个点从唯一的入边继承唯一的值;一旦某点被两个不同的定义到达,它必然是某两个定义点(或定义点与已插入的 φ)的 join 点,那里已有 φ 将其归约为一个新定义。归纳成立,后续不再产生新歧义。

### 幂等性

$\mathscr{J}(S\cup\mathscr{J}(S))=\mathscr{J}(S)$ 正是充分性论证的副产品:插入的 φ 全都落在**已有定义对**的汇合点上;而任意两条从新集合里的块出发、只在该点相遇的路径,拼接到原路径上后仍然构成原集合中某对块的汇合。

这与经典算法中常见的 $\text{DF}^{+}$ 迭代写法形成有趣的对照:那里要反复迭代

$$
\text{DF}(D_v),\ \text{DF}(D_v \cup \text{DF}(D_v)),\ \dots
$$

而从 join set 的定义出发,**迭代被定义本身吃掉了**。

### 结论

**最小放置是唯一的**。这一点很有用:你可以拿 $\mathscr{J}(D_v)$ 当作标尺,校验"我这份 SSA 是不是 minimal",无需任何数据流分析。

## 5. 经典算法为什么用 $\mathscr{J}(D_v\cup\{r\})$

传统 SSA 构造算法会把 CFG 入口节点 $r$ 也并入定义点集合,在 $\mathscr{J}(D_v\cup\{r\})$ 处插入 φ。多出来的那个 φ 是怎么回事?

### 动机:循环头的初值问题

考虑只在循环体内定义的变量:

```
  r ──┐
      ▼
  L:  x 被使用(循环头)
  ▲   │
  │   ▼
  B: x = x + 1 ──┘   (v 的唯一定义点)
```

这里 $D_v = \{B\}$,$\mathscr{J}(\{B\}) = \varnothing$——严格按 SRDP,一个 φ 都不用。但 $x$ 在**第一轮迭代**根本没有定义。

把 $r$ 视为"初值(未定义 / ⊤)的定义点"后,路径 $r \to L$ 与 $B \to L$ 只在 $L$ 相遇,于是 $L \in \mathscr{J}(\{B,r\})$,循环头得到 φ。这就是原文所谓"there are good reasons for that"。

### 代价:过度近似

```
      r
     / \
  A: x₁ = 1   B
     \       /
      D:  φ(x₁, x₁) ?
```

变量只在 $A$ 定义:

- $\mathscr{J}(\{A\}) = \varnothing$——单个定义,不需要 φ;
- $\mathscr{J}(\{A, r\}) = \{D\}$——路径 $r \to B \to D$ 与 $A \to D$ 只在 $D$ 相遇。

于是经典放置会在 $D$ 插一个 $\phi(x_1, x_1)$。**这个 φ 在 SRDP 意义上并非必需**,它是加入 $r$ 带来的过度近似,一跑 copy propagation(或 φ 的等价操作数折叠)就消失了。

### 由此得到的三点结论

1. 经典技术放置的是 $\mathscr{J}(D_v \cup \{r\})$,而非严格的 $\mathscr{J}(D_v)$;
2. 因此"经典 SSA"未必严格 minimal,而 minimality 只是**质量指标**——没有任何优化依赖"严格 minimal"(原文明确写道:"We are not aware of any optimizations that require a strict enforcement of minimality property");
3. 在**可归约流图**上,把这种非最小 SSA 规约回最小 SSA 是廉价的(§3.3)——机制就是 copy propagation:冗余 φ 的操作数在重命名后全部相等,φ 退化为一次普通拷贝,把其所有 use 改指到那个值上,φ 即消失。

---

## 6. 最容易混的一点:minimal ≠ pruned

| 变体 | 判定规则 |
|---|---|
| **minimal** | φ 放在 $\mathscr{J}(D_v \cup \{r\})$,**只看定义点的位置结构** |
| **semi-pruned** | 在其基础上,再要求变量在 join 处 live-in |
| **pruned** | 再要求变量在 φ 处是活的(等价于 liveness 分析 + 冗余 φ 消除) |

关键差别:**minimality 完全不看 use / liveness,也不看"值是否真的相同"**。它是纯结构性的,由 $D_v$ 和 CFG 形状唯一决定。因此最小放置里仍然可能留着:

- **死变量的 φ**:两个分支都给 $x$ 赋值,但汇合后 $x$ 再没被使用。严格按 SRDP,两个定义都到达汇合点,φ 必须插;要省掉它得靠 liveness(即 pruned),甚至需要先做死代码消除。
- **值相同的 φ**:`if (c) x = 1; else x = 1;` 是两个**定义点**(不是两个值),所以 minimal 依然会在汇合处插入 $\phi(x_1, x_2)$。

反过来说,$\mathscr{J}$ 的规范性正是它的价值所在:你可以逐变量独立地拿放置结果与 $\mathscr{J}(D_v \cup \{r\})$ 对照来判定 minimality。

## 7. 工程实践

1. **非强制要求**。没有任何优化必须严格满足极小性。多插冗余 φ 不破坏正确性,只增加一点开销。
2. **价值所在**。φ 越多,SSA 销毁时展开出的并行拷贝就越多,直接转化为寄存器分配阶段的拷贝消解负担与寄存器压力——即 PHIElimination 与 swap problem 那条链路。
3. **实现简单**。仅在汇合集处插 φ,对 CFG 做一次拓扑遍历即可完成,算法成本很低(第 4 章 §4.4)。
4. **经典算法的微调**。传统算法用 $\mathscr{J}(D_v \cup \{r\})$,统一处理未初始化变量、简化算法逻辑(第 5 节)。
5. **可后期转换**。对可归约流图,即使先得到非极小 SSA,也能通过 copy propagation 轻松转为极小 SSA。

### 两条达到最小的路径

- **经典法**:$\text{DF}^{+}(D_v \cup \{r\})$ + 重命名(第 3 章);
- **直接法**:直接计算 join set,按 CFG 拓扑序遍历一次(第 4 章 §4.4)。

### 更常见的工程选择:事后修补

保守地多插(例如对每个多前驱块都插),再靠 copy propagation / φ 化简收敛到最小。代码更简单、更健壮,在可归约流图上效果很好。

## 8. 一个完整例子

```c
if (cond) {
    x = 1;     // 定义点 1,位于块 A
} else {
    x = 2;     // 定义点 2,位于块 B
}
print(x);      // 使用点,位于块 C
```

对应 CFG:

```
        cond
       /    \
   A: x₁=1   B: x₂=2
       \    /
        C: x₃ = φ(x₁, x₂)
           print(x₃)
```

- $D_x = \{A, B\}$,两个互异定义点;
- 路径 $A \to C$ 与 $B \to C$ 恰在 $C$ 汇合,故 $\mathscr{J}(\{A,B\}) = \{C\}$;
- **满足极小性**:只在 $C$ 插入 1 个 φ;
- **非极小的冗余做法**:在 $A$ 或 $B$ 内部也插 φ,对正确性毫无帮助,纯属多余。

若把 $r$ 并入集合(经典算法),由于 $r$ 到 $C$ 必经过 $A$ 或 $B$,而 $A, B$ 已含定义,$\mathscr{J}$ 不会新增节点,结论不变——这也说明加 $r$ 只在**循环头**这类"返回边"结构上才会额外产生 φ。

---

## 9. 小结

- 极小性约束的是 **φ 插入阶段**,描述的是"已插入 φ 但尚未重命名"的代码。
- 它的是非判据是**结构性的**:给定 $D_v$ 与 CFG 形状,最小插入位置集合 $\mathscr{J}(D_v)$ 唯一确定,与 use、liveness、值是否相同都无关。
- 汇合点的定义要求两个起点**互异**,由此直接得到"单定义变量无需 φ"。
- 幂等性 $\mathscr{J}(S \cup \mathscr{J}(S)) = \mathscr{J}(S)$ 表明闭包一次到位,无需递归迭代——这是与 $\text{DF}^{+}$ 迭代写法的一个重要对照。
- 经典算法用 $\mathscr{J}(D_v \cup \{r\})$ 以处理循环头初值,代价是可能插入在 SRDP 意义上非必需的冗余 φ,可由 copy propagation 消除。
- **minimality 是规范形式目标,不是正确性前提。** 它值得在意,是因为 φ 数量会一路影响到 SSA 销毁与寄存器分配的成本。
